# Security

Silkpay is a hackathon MVP. It is **not audited** and must not be used with real funds.

- The demo uses a cookie-based user switcher instead of real authentication.
- Smart contracts are deployed to Sepolia only. No mainnet deploy without a completed audit.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/hu-oscar/silkpay/security/advisories/new).
